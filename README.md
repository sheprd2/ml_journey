# ml_journey

My machine learning learning journey, one small project at a time.

## Contents

- `rain.py` – exploratory analysis of Indian rainfall data (1901–2015) with pandas. Focuses on the Kerala subdivision: finds the wettest year, computes average monthly rainfall, the overall annual mean, and counts years with above-average rainfall.
- `rainfall in india 1901-2015.csv` – dataset with monthly, seasonal and annual rainfall (mm) per meteorological subdivision.

## Usage

```bash
pip install pandas
python rain.py
```
